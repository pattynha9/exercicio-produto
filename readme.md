EXERCÍCIO ESTOQUE DE LOJA DE PRODUTOS

Neste exercício, vamos criar um programa para gerenciar o estoque de produtos de uma loja.
O programa deverá receber o nome do produto.
A quantidade inicial em estoque deverá ser 0 unidades.
Um menu deverá ser exibido para que o usuário escolha entre as seguintes opções:

1 - Adicionar produtos ao estoque: aumentar a quantidade em estoque.
2 - Remover produtos do estoque: diminuir a quantidade em estoque.
3 - Consultar estoque: imprimir o nome do produto e a quantidade disponível.
4 - Sair do programa.

Ao adicionar ou remover produtos, o programa deverá solicitar a quantidade desejada.
Não será permitido remover uma quantidade maior do que a disponível em estoque. Caso isso aconteça, deverá ser exibida uma mensagem informando que não há produtos suficientes.

Caso o usuário escolha um número que não esteja na lista, o programa deverá exibir uma mensagem de opção inválida e apresentar o menu novamente até que uma opção válida seja escolhida.

Para desenvolver esse aplicativo, precisaremos:

Criar uma função que exiba o menu e valide a opção escolhida.
Criar uma função para adicionar produtos ao estoque.
Criar uma função para remover produtos do estoque.
Criar uma função para imprimir os dados do estoque.

Utilizar uma estrutura de repetição para manter o menu funcionando até que o usuário escolha sair.
 
Desafio: Quando escolher a opção 4 o programa deverá exibir uma mensagem informando o nome do produto e a quantidade final disponível em estoque.
